# Sheaf MVP — App Store 两周上线计划

> **目标：** 两周内提交 Mac App Store 审核，让用户 5 分钟内完成「写 Markdown → 导出可发布内容」。

**产品定位：** Sheaf 不是 Markdown 编辑器，是**本地优先的内容分发工具**。

> Write once, publish beautifully.

**核心数据模型：**

```
输入：Markdown 文本
中间态：解析后的文章结构（标题、段落、列表、引用、代码块、图片）
输出：公众号 HTML | 小红书卡片 PNG | 长图 PNG
```

**技术栈：** Vue 3 + Tauri 2 + CodeMirror + markdown-it（现有栈，不重写）

---

## MVP 必须包含

| # | 功能 | 说明 |
|---|------|------|
| 1 | Markdown 编辑与预览 | 已有 CodeMirror / markdown-it，继续打磨 |
| 2 | 公众号排版导出 | 一键复制 HTML 到剪贴板，样式内联 |
| 3 | 小红书卡片导出 | 3–9 张 PNG，3:4 比例，内置 3 套模板 |
| 4 | 长图导出 | 单张 PNG，一个干净模板 |
| 5 | 示例内容 | 内置 3 篇 demo（产品发布 / 知识笔记 / AI 工具分享） |
| 6 | 官网落地页 | 定位 + 场景 + 效果图 + 下载 + 隐私政策 |

---

## 坚决不做（两周内）

- 插件系统
- WASM runtime
- Agent skill
- 模板商店
- 用户账号 / 云同步
- 订阅付费
- 多语言完整支持
- 自动发布到平台
- AI 写作助手

---

## 两周排期

### 第 1–2 天：定产品骨架

**目标：** 用户打开就知道「粘贴 Markdown → 选排版 → 导出」。

- [ ] 首页 / 空状态改为导出导向文案
- [ ] 准备 3 篇 demo 内容
- [ ] 布局：编辑区 | 预览区 | 导出面板
- [ ] 产品文案：免费、本地优先、无需登录

**验收：**

- 新用户不用教程知道下一步点哪里
- 10 秒内能看到示例文章和导出入口

---

### 第 3–5 天：公众号导出

**目标：** 最实用的第一个导出能力。

- [ ] Markdown → 公众号 HTML 转换
- [ ] 内置 2–3 套公众号样式
- [ ] 复制 HTML 到剪贴板
- [ ] 复制纯文本（备用）
- [ ] 导出前预览

**技术要点：**

- 样式必须内联（公众号编辑器兼容）
- 支持：标题、段落、引用、列表、代码块、图片
- 复制失败要有明确提示

**验收：**

- 粘贴到公众号后台后样式基本保持
- 1000–2000 字文章可正常复制和发布预览

---

### 第 6–8 天：小红书卡片导出

**目标：** 传播性最强的功能。

- [ ] Markdown 按标题 / 段落切分为卡片
- [ ] 固定比例 3:4
- [ ] 导出 PNG
- [ ] 内置 3 套模板：极简白、黑金、杂志风
- [ ] 支持标题页、正文页、结尾引导页

**不做：**

- 自由拖拽编辑
- 花哨排版器
- 无限自定义

**验收：**

- 一篇文章生成 3–9 张图
- 图片可直接发小红书
- 文字不溢出、不截断

---

### 第 9–10 天：长图导出

**目标：** 补齐引流长图场景。

- [ ] 文章渲染为单张长图
- [ ] 顶部标题 + 正文 + 底部引导语
- [ ] 导出 PNG
- [ ] 极长内容限制 + 提示

**验收：**

- 适合朋友圈、社群、知识星球、即刻
- 文字清晰，不糊，不截断

---

### 第 11 天：App Store 准备

**目标：** 别死在上架流程。

- [ ] 检查 macOS sandbox 权限
- [ ] 收紧 Tauri 安全配置（CSP、asset scope）
- [ ] App Icon
- [ ] 隐私政策页面
- [ ] 支持页面
- [ ] App Store 截图（6 张）
- [ ] 中英文描述

**注意：** 已有签名和 profile 配置，仍需逐项查权限、沙盒、文件访问、隐私说明。

---

### 第 12 天：稳定性测试

**测试清单：**

- [ ] 新建文章
- [ ] 打开 `.md` 文件
- [ ] 保存 `.md` 文件
- [ ] 最近文件
- [ ] 切换主题
- [ ] 复制公众号 HTML
- [ ] 导出小红书 PNG
- [ ] 导出长图 PNG
- [ ] 无网络状态启动
- [ ] 首次安装启动
- [ ] 删除配置后启动

**验收：**

- 核心流程连续跑 10 次不崩
- 无空白页、无导出无响应、无吓人权限弹窗

---

### 第 13 天：官网和发布材料

**官网结构：**

1. 一句定位：`Write once, publish beautifully.`
2. 三个场景：公众号、小红书、长图
3. 六张导出效果图
4. 免费、本地优先、无需登录
5. 下载按钮
6. 隐私政策
7. 联系方式

---

### 第 14 天：提交 App Store

- [ ] 打包 release

- [ ] 填写隐私信息

## 后续迭代（MVP 之后）

按用户反馈决定是否做：

1. 更多平台模板（LinkedIn、X、Medium）
2. 自定义品牌样式
3. 模板市场 / 插件系统
4. WASM 重计算导出
5. Agent skill 集成

**原则：** 有人开始问「能不能加某平台 / 自定义模板 / 装别人模板」时，再做插件。否则是自嗨。

---

## 风险提醒

- **最大风险：** 做成「工程师觉得很牛、用户完全无感」的东西
- **刀口要窄：** 插件、WASM、agent skill 以后再说
- **唯一任务：** 让 Sheaf 变成能生成漂亮发布物的极简工具
