Sheaf — 本地 AI Markdown 编辑器

Sheaf 是 reaidea 出品的 macOS 原生 Markdown 编辑器，采用本地优先设计：文稿与设置保存在你的磁盘，无需注册账号，也不依赖云端同步。

核心功能

  • 分屏实时预览：等宽编辑区与衬线预览区同步滚动，支持纯编辑、纯预览与分屏三种视图
  • 大纲导航：自动提取标题层级，点击即可跳转
  • AI 段落改写：用自然语言描述修改意图，审阅 diff 后一键应用；每次应用前自动保存版本快照
  • 富文本排版：KaTeX 数学公式、Mermaid 流程图、代码语法高亮、中英文自动间距
  • 导出：PDF、微信公众号 HTML、小红书分享卡片与长图
  • AI 服务商：支持 MiniMax、通义千问及自定义 OpenAI 兼容接口

技术栈：Tauri v2、Vue 3、CodeMirror 6、markdown-it。开源协议：AGPL-3.0。

Sheaf — Local AI Markdown Editor for macOS

Sheaf is a native macOS Markdown editor by reaidea. It is local-first: your documents and settings stay on disk with no account or cloud sync required.

Key features

  • Split live preview with synchronized monospace editor and serif preview
  • Outline panel with click-to-jump heading navigation
  • AI paragraph rewrite with diff review, version snapshots, and one-click apply
  • Rich typography: KaTeX math, Mermaid diagrams, syntax highlighting, CJK spacing
  • Export to PDF, WeChat HTML, Xiaohongshu cards, and long images
  • AI providers: MiniMax, Qwen, and custom OpenAI-compatible endpoints

Built with Tauri v2, Vue 3, and CodeMirror 6. Licensed under AGPL-3.0.
